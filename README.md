# 🎥 YouTube Clone

## 📖 Project Overview

This project is a front-end clone of YouTube built using HTML and CSS.

The project recreates the YouTube homepage interface including:
- Header Navigation
- Sidebar Menu
- Search Bar
- Video Grid Layout
- Channel Information
- Video Recommendations

---

## ✨ Features

- YouTube-inspired homepage UI
- Responsive layout
- Sidebar navigation menu
- Search bar design
- Video thumbnails
- Channel profile pictures
- Video duration labels
- Clean CSS styling

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Flexbox
- CSS Grid

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Bhavitha13541/YOUTUBE-HTML-CSS.git
```

2. Open the project folder

3. Open `youtube.html` in your browser
